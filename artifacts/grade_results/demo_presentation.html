Evaluation Demo

Turning Evaluation Theory into Engineering Practice

🎭 The Narrative

We built a Multi-Agent E-Commerce Checkout Concierge. In early iterations, the billing logic contained severe boundary vulnerabilities (e.g., negative checkout totals, discount rates exceeding 100%).

Our goal is to implement a robust Hybrid Evaluation Pipeline to discover these issues, execute adversarial scenarios, and automate quality guardrails before the agent hits production.

⚙️ Step 1: Local Property-Based Testing

We use Open-Source Property-Based Testing (Pytest + Hypothesis) for cheap, millisecond boundary logic verification. This automatically generates hundreds of edge-case math inputs to catch basic arithmetic bugs before they ever reach the LLM.

🛡️ Step 2: Adversarial Red-Teaming & LLM-as-a-Judge

We deployed a local LLM-as-a-judge (agents-cli eval run) to grade the agent against a curated adversarial dataset. The dataset simulates malicious users attempting to bypass card charging, apply multiple coupons at once, and inject prompts.
